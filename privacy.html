Privacy Policy

Last updated: 8 September 2026

Video Creator ("the application") is a personal command-line tool operated by its developer to upload self-produced videos to the developer's own YouTube channel. This policy explains what data the application accesses through Google APIs and how it is handled.

Information the application accesses

The application requests the following Google OAuth scopes: youtube.upload and youtube. They are used exclusively to upload videos, set video metadata (title, description, tags, scheduled publish time) and set thumbnails on the channel of the authenticated user.

How data is stored and used

  • The OAuth access and refresh tokens are stored only in a local file on the developer's computer.
  • No Google user data is transmitted to any third party, server or analytics service.
  • No personal information about viewers, subscribers or any other person is collected or read.
  • The application does not sell, share or use Google user data for advertising.

Google API Services User Data Policy

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, or by deleting the local token file.

Contact

Questions about this policy: open an issue at github.com/chuotnhat1985/video_generator.
